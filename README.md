# Personal Website

*A personal space for sharing my thoughts, experiences, and reflections on life*

- [Resume](https://ziyiweng.github.io/resume.pdf)

Built with [Astro](https://astro.build/) and hosted on GitHub Pages.

Published posts live in the private `ziyiweng-blog-content` repository. For local development, keep that checkout at `../ziyiweng-blog-content`. `npm run dev` and `npm run build` copy `published/` into `src/content/blog/`. Those copies are gitignored. Files in `drafts/` are not copied.
