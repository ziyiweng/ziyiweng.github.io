# ziyiweng.github.io

Hosts my CV: **https://ziyiweng.github.io/CV/CV.pdf**

Edit `cv-src/cv.tex` and push to `main`; GitHub Actions compiles it and republishes the PDF (~2 min).

Build locally (optional): `cd cv-src && latexmk -pdf cv.tex`

One-time setup: Settings → Pages → Source: **GitHub Actions**.
